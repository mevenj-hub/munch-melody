# 🎹 Munch Melody
An interactive web application that transforms YouTube links into falling-note piano tutorials with adjustable difficulty levels (Easy, Medium, Hard), featuring an interactive synthesizer keyboard and Synthesia-style waterfall visualizer.

## Features
* **Interactive Synthesizer Keyboard:** Play notes directly via mouse clicks or touch.
* **Synthesia Waterfall Visualizer:** Real-time falling-note animation synced with audio.
* **Preset Songs:** Instant access to classics like Fairouz (*Qadish Kan Fi Nas*), Beethoven, and Pachelbel.
* **Difficulty Customization:** Switch between Easy, Medium, and Hard views.
